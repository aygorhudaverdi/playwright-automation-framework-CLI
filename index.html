QA Playground

A static, no-backend UI automation practice target. Each page below exercises a different automation scenario — forms, waits, alerts, drag-and-drop, iframes, shadow DOM, and more. Every interactive element carries a stable id and data-testid attribute so you can write reliable Selenium, Playwright, or Cypress locators against it.

Form Inputs
Text, textarea, select, radio, submit & validation states.
Login Form
Client-side validated login with success/error states.
Checkboxes
Independent, pre-checked, and indeterminate checkboxes.
Dropdowns
Native <select> plus a custom JS dropdown.
Dynamic Loading
Elements that appear after a delay — practice explicit waits.
Dynamic Content
Content and attributes that change on every reload/click.
JS Alerts
alert(), confirm(), and prompt() dialogs.
Modals
In-page modal dialog with focus trap and overlay dismiss.
Sortable Table
Click-to-sort columns and row-level actions.
Drag and Drop
HTML5 drag-and-drop between source and target boxes.
Hover Reveal
Captions and actions that only render on hover.
File Upload
File input plus a drag-and-drop upload zone.
iFrames
Editable content and nested frame context switching.
Shadow DOM
A native web component with encapsulated markup.
Infinite Scroll
Items appended on scroll — practice scrolling & polling.
Key Presses
Reports the last key pressed, for send-keys style tests.
Context Menu
Custom right-click menu, native oncontextmenu.
Broken Images
A mix of valid and broken <img> sources.
Slow Elements
Buttons with artificial latency and progress states.
