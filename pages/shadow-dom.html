Shadow DOM

A native web component with an open shadow root. Regular document.querySelector cannot see inside it — you need to pierce the shadow root explicitly.

<qa-counter> custom element

Notes

  • Shadow root mode: open (accessible via element.shadowRoot).
  • The increment button and count display both live inside the shadow tree.
  • Playwright pierces open shadow roots automatically with normal locators; Selenium needs explicit shadowRoot traversal.
